# إذاعة مدرسية احترافي — نسخة الحاسوب

تطبيق سطح مكتب مستقل تمامًا عن نسخة الهاتف ([school-radio-android](https://github.com/saidjte/school-radio-android))، مخصص لغرفة الإذاعة المدرسية: واجهة واحدة مكيّفة لشاشة الحاسوب تدمج الأقسام المتفرقة في نسخة الهاتف لتسهيل التسجيل والبث المباشر.

## الوظائف الأساسية الثلاث

1. **البث المباشر للميكروفون** — اختيار جهاز الإدخال، مقياس مستوى حي، سماع مراقب اختياري، وتسجيل WAV أثناء البث.
2. **تشغيل الموسيقى** — قائمة تشغيل WAV/MP3 مع بحث زمني وتحكم بالصوت وتنقل بين المقاطع وانتقال تلقائي.
3. **التسجيلات** — مكتبة تسجيلات: تشغيل، إعادة تسمية، حذف، تغيير المجلد.

كل المعالجة الصوتية محلية 100% على الجهاز — لا إنترنت، لا رفع، لا خدمات خارجية.

## التشغيل

- **ويندوز:** ثبّت `SchoolRadioDesktop_vX.Y.Z-windows-x64.msi` من صفحة الإصدارات (يتضمّن جافا مدمجًا).
- **أي نظام عبر جافا:** `java -jar SchoolRadioDesktop_vX.Y.Z-<نظام>.jar` (يتطلب جافا 17 أو أحدث).

## البناء

```bash
./gradlew build                          # ترجمة + اختبارات وحدوية
./gradlew packageUberJarForCurrentOS     # حزمة تشغيل لنظام البناء الحالي
./gradlew packageMsi                     # مثبّت ويندوز (على ويندوز فقط)
```

## الإصدارات

- `version.properties` هو المصدر الوحيد للحقيقة بشأن رقم الإصدار.
- أي دفع إلى `main` يشغّل CI: بناء حزم Windows/Linux/macOS + مثبّت MSI، ثم نشر Release تلقائي برقم الإصدار من `version.properties`.
- وضع فحص ذاتي بلا واجهة: `java -jar SchoolRadioDesktop.jar selftest`.

## المعمارية باختصار

- **Kotlin + Compose Multiplatform (Desktop)** — واجهة RTL عربية واحدة بثلاثة أقسام.
- **Java Sound** — التقاط الميكروفون (`TargetDataLine`)، السماع المراقب (`SourceDataLine`)، وتشغيل PCM (WAV).
- **JLayer** — فك MP3 إطارًا بإطار مع بحث زمني بإعادة فتح وعدّ سريع للإطارات.
- محلّل ترويسات MP3/WAV خالص (Kotlin) لمدد الملفات في المكتبة وقائمة التشغيل — مغطى باختبارات وحدوية.
