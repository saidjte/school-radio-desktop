# إذاعة مدرسية احترافي — نسخة الحاسوب

تطبيق سطح مكتب مستقل تمامًا عن نسخة الهاتف ([school-radio-android](https://github.com/saidjte/school-radio-android))، مخصص لغرفة الإذاعة المدرسية: واجهة واحدة مكيّفة لشاشة الحاسوب تدمج الأقسام المتفرقة في نسخة الهاتف لتسهيل التسجيل والبث المباشر.

## الوظائف

**الوظائف الأساسية الثلاث:**

1. **البث المباشر للميكروفون** — اختيار جهاز الإدخال، مقياس مستوى حي، سماع مراقب اختياري، وتسجيل WAV أثناء البث.
2. **تشغيل الموسيقى** — قائمة تشغيل WAV/MP3 مع بحث زمني وتحكم بالصوت وتنقل بين المقاطع وانتقال تلقائي.
3. **التسجيلات** — مكتبة تسجيلات: تشغيل، إعادة تسمية، حذف، تغيير المجلد.

**جديد v0.3.0 — الاستوديو المدمج:**

6. **الاستوديو المدمج (الشاشة الرئيسية)** — الجدولة + السكريبت + البث في شاشة واحدة للإذاعة:
   - عمود الجدولة: فقرات الحلقة بحالاتها وساعاتها المخططة ولوحة التشغيل الحي (بدء الحلقة، الفقرة التالية، مؤشر التقدم وتحذير التجاوز).
   - لوحة السكريبت: قراءة كبيرة الخط تنتقل **آليًا** إلى سكريبت الفقرة الجارية عند ربطهما، مع مؤشر مصدر النص (من الجدولة / اختيار يدوي) ووضع قراءة السكريبت كاملًا.
   - عمود البث: الميكروفون (بدء/إيقاف، مقياس حي، سماع مراقب، تسجيل) + الموسيقى (تشغيل/تنقل/صوت/إضافة ملفات) + التسجيلات (أحدث التسجيلات وتشغيلها السريع) — بلا تنقّل بين الأقسام.
   - شريط علوي: مؤشر «على الهواء» المجمّع من كل مصادر الصوت + ساعة حية.
   - ربط الفقرات بالسكريبت: من محرّر الفقرة يمكن اختيار «السكريبت المرتبط»، ويظهر شعار «سكريبت ✓» في القائمتين.

**جديد v0.2.0:**

4. **سكريبت المذيع** — كتابة فقرات النص وتحريرها وترتيبها (إضافة/تحرير/حذف/أعلى-أسفل) مع لوحة قراءة كبيرة الخط للعرض على الهواء، وأزرار تكبير/تصغير الخط، وعدّاد كلمات وزمن قراءة تقديري لكل فقرة ولكل السكريبت. يُحفظ تلقائيًا في `script.json`.
5. **جدولة الفقرات** — فقرات الحلقة مرتبة بالأداء، لكل فقرة: نوع (بث مباشر / موسيقى / تسجيل / كلمة-قراءة) ومدة مخططة وملف صوتي مرتبط اختياري من الموسيقى أو التسجيلات، وساعة بداية للحلقة تحسب ساعة بدء كل فقرة. مع **لوحة التشغيل الحي**: بدء الحلقة، إنهاء الفقرة ← التالية، عدّاد زمن لكل فقرة مع مؤشر تقدم وتحذير تجاوز المدة، وحالات (جارية/منتهية/قادمة). يُحفظ تلقائيًا في `schedule.json`.

كل المعالجة الصوتية محلية 100% على الجهاز — لا إنترنت، لا رفع، لا خدمات خارجية.

## التشغيل

- **ويندوز:** ثبّت `SchoolRadioDesktop_vX.Y.Z-windows-x64.msi` من صفحة الإصدارات (يتضمّن جافا مدمجًا).
- **أي نظام عبر جافا:** `java -jar SchoolRadioDesktop_vX.Y.Z-<نظام>.jar` (يتطلب جافا 17 أو أحدث).

## البناء

```bash
./gradlew build                          # ترجمة + اختبارات وحدوية
./gradlew packageUberJarForCurrentOS     # حزمة تشغيل لنظام البناء الحالي
./gradlew packageMsi                     # مثبّت ويندوز (على ويندوز فقط)
```

## الإصدارات

- `version.properties` هو المصدر الوحيد للحقيقة بشأن رقم الإصدار.
- أي دفع إلى `main` يشغّل CI: بناء حزم Windows/Linux/macOS + مثبّت MSI، ثم نشر Release تلقائي برقم الإصدار من `version.properties`.
- وضع فحص ذاتي بلا واجهة: `java -jar SchoolRadioDesktop.jar selftest`.

## المعمارية باختصار

- **Kotlin + Compose Multiplatform (Desktop)** — واجهة RTL عربية: استوديو مدمج بثلاثة أعمدة + خمسة أقسام تفصيلية.
- **Java Sound** — التقاط الميكروفون (`TargetDataLine`)، السماع المراقب (`SourceDataLine`)، وتشغيل PCM (WAV).
- **JLayer** — فك MP3 إطارًا بإطار مع بحث زمني بإعادة فتح وعدّ سريع للإطارات.
- **Gson** — تخزين ذرّي للسكريبت والجدولة (`script.json` / `schedule.json`) بمجلد بيانات المستخدم.
- محلّل ترويسات MP3/WAV خالص (Kotlin) لمدد الملفات، ورياضيات جدولة وحسابات قراءة خالصة — كلها مغطاة باختبارات وحدوية.
